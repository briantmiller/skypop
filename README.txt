SKY POP PILOT - install on iPad as an app
=========================================

This folder is a complete Progressive Web App. It needs to be served from a
web address (https) once; after that it works offline from the Home Screen.

1. Put it online (free, about 2 minutes) - pick one:
   - Netlify Drop: go to https://app.netlify.com/drop and drag this whole
     "sky-pop-pilot" folder onto the page. You get a link like
     https://something.netlify.app
   - GitHub Pages: create a repository, upload these files, then turn on
     Settings > Pages.

2. On the iPad, open that link in Safari.
3. Tap the Share button, then "Add to Home Screen", then "Add".
4. Launch "Sky Pop" from the Home Screen. It opens full screen, in landscape,
   and keeps working without internet.

Controls
  Arrow pad (left thumb): up / down / turn left / turn right
  Faster / Slower (right thumb): speed
  POP! (hold it): shoot. Shots steer themselves toward the target inside the
  red dashed ring, so little pilots hit often.
  House button: back to the hangar to pick a new aircraft or color.

No crashing, no losing - the plane can't hit the ground. Every 5 pops gets a
cheer. On a keyboard: arrow keys, W/S for speed, Space to shoot.
